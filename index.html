CNN 브라우저 이식

Keras 3 모델을 TF.js에서 로드하지 못해 model.json의 입력 shape와 weight prefix를 패치하고, 캔버스 입력 전처리를 학습 데이터와 맞췄습니다.

결과와 배운 점

단일 서버에서는 보이지 않던 WebSocket 메시징의 분산 환경 가정을 확인했고, AI 모델도 학습 정확도뿐 아니라 브라우저 로딩 포맷과 입력 전처리까지 서비스 흐름 안에서 맞춰야 한다는 점을 배웠습니다.

Project 03 · 3/3

ZipCheck · 문제 해결

720만 건 실거래가 조회 병목을 실행계획과 인덱스로 개선했습니다.

트러블슈팅: 720만 건 실거래가 조회 병목

문제
WHERE/JOIN 컬럼에 함수가 적용되어 Full Table Scan 발생

거래 금액은 쉼표 포함 VARCHAR라 CAST/REPLACE가 필요했고, 지역 JOIN은 LEFT(dong_code, 5)를 사용했습니다. 함수가 적용된 컬럼은 인덱스를 타지 못해 720만 건 규모에서 조회 비용이 급증했습니다.

해결

가격은 deal_amount_num, 지역 JOIN은 sgg_prefix Generated Column(STORED)으로 분리해 인덱스를 부여했습니다.

보완

아파트 + 날짜/면적/금액 조합 복합 인덱스 3종과 JOIN용 인덱스를 추가했습니다.

검증

SQL Profiling과 EXPLAIN으로 CPU 시간과 실행 계획 변화를 확인했습니다.

성과

CPU User Time437.5ms→1ms 미만
